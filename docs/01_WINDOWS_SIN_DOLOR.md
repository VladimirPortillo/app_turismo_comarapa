# Windows sin dolor

Ruta recomendada:
Windows -> Flutter -> Android.

Plan B:
Windows -> Flutter -> Chrome.

No necesitas Visual Studio para Android o Chrome.

Preparar:
`scripts\00_PREPARAR_WINDOWS.bat`

Ejecutar:
`scripts\01_MENU_WINDOWS.bat`

Carpeta sugerida:
`C:\flutter_aula\PROYECTO_FINAL_360_SESION2_FINAL`

Evitar:
- OneDrive
- Program Files
- rutas de red
- rutas extremadamente largas
